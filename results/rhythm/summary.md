## 手法

- markdown 前処理: コードブロック・見出し・表・罫線・画像・URL を除去、リンクとインラインコードは中身を残す。箇条書きはマーカーを外して文として保持。
- 文分割: 。！？ + 改行 (coji/natural-japanese lint.py 準拠)。日本語文字を含まない文は除外。
- モーラ近似: MeCab + unidic-lite の pron フィールド (カタカナ発音) から、小書き仮名 (ャュョァィゥェォヮ) を直前拍に併合してカウント (natural-japanese 準拠)。ー・ッ・ンは各1モーラ。読みが得られない token (英語識別子等) は 0 モーラ。
- burstiness B = (σ−μ)/(σ+μ)、σ は母標準偏差 (出典: Goh & Barabási 2008, EPL 81:48002。文長系列への適用は natural-japanese に倣う)。
- 体言止め: 文末の実質形態素 (句読点・括弧除く) の pos1 が 名詞。リスト項目は名詞終わりが書式上普通なので **地の文のみ** で算出。文末bigram TTR も同様に地の文のみ。
- Cohen's d: 二標本 pooled SD、文書レベル。正の d = AI が大。95% CI は bootstrap (n=2000, seed=20260717)。Mann-Whitney U (両側) + Holm 補正 (13指標) を参考併記。

## 所見

### 人間 vs AI で差が大きかった指標トップ3

1. **burstiness (文字長)**: d = −0.96 [−1.12, −0.81]。AI は文長系列の burstiness が一貫して低い = 文長がリズミカルに揺れず単調。
2. **burstiness (モーラ長)**: d = −0.80 [−1.00, −0.62]。文字ベースと同方向・同規模で、表記ゆれではなく音韻リズムの単調さとして再現。
3. **段落あたり文数CV**: d = −0.67 [−0.83, −0.50]。AI は段落の文数が揃いすぎる（「3文段落を等間隔に積む」型）。

次点: 文長CV (文字) d = −0.56。上位4指標がすべて「変動・揺らぎの欠如」系であり、
coji/natural-japanese の主張「AI臭は語彙よりリズム（単調さ）に出る」と方向が一致する。
語彙指標との判別力の直接比較 (H1) は Phase 3 で行う。

### 方向の一貫性（モデル横断）

burstiness (文字長)・段落あたり文数CV・文長CV (文字) は **7モデル全てで人間より低い**
（burstiness の per-model d: −0.59〜−1.72）。単調化はモデル・世代・系列を問わず共通。
程度には差があり、GPT-3.5/GPT-4o が最も単調 (burstiness d ≈ −1.4〜−2.2)、
Claude Sonnet 4 / Opus 4 / gpt-oss-20b が最も人間に近い (d ≈ −0.3〜−0.6)。

### H2 予備検分（リズム指標のモデル間ばらつき）

- コアなリズム指標（文長CV・burstiness・段落CV）は between/within ratio 0.44〜0.58 に収まり、
  かつ全モデルが人間から同方向にずれる。**「方向はモデル間で均質、程度に中規模の差」**という様相。
- 一方、文末系の修辞指標はモデル間で強く分化する:
  - 体言止め率 (ratio 0.85): Claude Haiku / GPT-3.5 / GPT-4o はほぼ 0（0.003〜0.013）に対し、
    Claude Sonnet 4 / Opus 4 / gpt-oss-20b は 0.13〜0.22 と人間 (0.137) 並みかそれ以上。
  - 文末bigram TTR (ratio 1.32): llama3.2-1b 0.37 〜 gpt-oss-20b 0.91 と範囲が人間SDの2倍超。
- 予備所見としては「リズムの単調化は共通指紋、文末修辞はモデル固有指紋」という
  レイヤー構造が示唆される。ただし H2 の本検定（語彙指標のモデル間分散との対比・分散分析）は
  Phase 3 で行う。

## 要確認 (Phase 3 への持ち越し)

1. **文末bigram TTR の文書長非統制**: TTR は文数に依存し、人間文書（平均80.9文）は
   AI文書（平均38.5文）より不利に出る。d = +0.24 は過大評価の可能性が高い。
   Phase 3 で MATTR / 窓固定TTR に置き換えて再計測する。【要確認】
2. **llama3.2-1b の縮退出力**: 文長SD 125.9±503.1、読点/文 2.81±7.43 と極端な外れ値を含む
   （改行のない長大出力の縮退とみられる）。AI全体の mean±SD を歪めるため、
   Phase 3 では中央値・trimmed 統計での頑健性確認、または縮退文書の除外基準を定義する。【要確認】
3. **モーラ近似の限界**: 読みが得られない token（英語識別子・記号）は 0 モーラ扱い。
   英語混じり文でモーラ長が過小になる。文字長系指標と併読する前提。【要確認】
4. **リスト項目を文に含める設計**: natural-japanese の文分割（改行=文境界）に準拠したが、
   箇条書き密度という「構造」がリズム指標に混入する。体言止め率・文末TTRは地の文のみで
   部分対処済みだが、文長系は未分離。Phase 3 で prose-only 変種を併算して感度分析する。【要確認】
5. **「ではなく」の表記ゆれ**: literal「ではなく」のみ計上。「でなく」「じゃなく」は未計上。
6. **レジスタ交絡**: 人間コーパスは Qiita/Zenn 実記事（可変長・ジャンル混在）、AI は固定プロンプト
   生成。Phase 1 監査 P1#7 と同根の交絡が本指標にも乗る。テーマ層別の再計測は Phase 3。
7. **Mann-Whitney p は参考値**: rank ベースのため分布形状差に敏感で、d ≈ −0.1 の
   文長SDでも p が極小になる（AI の SD が狭い帯に密集するため）。効果量 (d + CI) を主とする。
8. **コーパス生成条件**: 元コーパス自体が temperature/seed 未固定で生成されている
   （Phase 1 監査 P0）。本 Phase の計測は決定的（乱数は bootstrap の seed=20260717 のみ）だが、
   コーパス側の再現性制約は引き継ぐ。
